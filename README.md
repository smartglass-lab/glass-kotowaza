# グラスことわざ — Glass Kotowaza

Meta Ray-Ban Display 用の**ことわざ学習アプリ**。よく知られたことわざ・慣用句を **120件** 収録し、「猫に□□」の□を当てる**あなうめクイズ**、ことわざ⇄意味の**いみクイズ**、←→でめくる**ずかん**の3つで、メガネの中で少しずつ覚えられる。まちがえた問題は自動で**にがて**に入り、にがてだけを出題して克服できる。タイトルには日付で決まる**きょうのことわざ**を1件表示。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-kotowaza.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / DOM / 静的サイト）

## 特徴

- **あなうめクイズ** — 「猫に□□」「石の上にも□□」の□に入ることばを4択で。まちがいの選択肢はほかのことわざの一部から文字数をそろえて選ぶので、「小判／真珠／念仏…」と迷える
- **いみクイズ** — ことわざ→意味、意味→ことわざの2方向がまざって出題。似た意味のことわざ（猫に小判と豚に真珠など）は同じ問題の選択肢に入れないので、正解がひとつに決まる
- **答えるたびに解説** — ○×の演出のあと、ことわざ全文・読み・意味をその場で表示
- **にがて** — まちがえたことわざは「にがて」に入り、にがてだけの10問で復習。正解すると「こくふく」して外れる
- **ずかん** — 五十音順に←→でめくり、↑↓で「あ行・か行…」をとぶ。読み・意味・**似た意味**・**反対の意味**のことわざ（急がば回れ⇔善は急げ、二度あることは三度ある⇔三度目の正直 など）つき。にがてだけ表示にも切り替え可能
- **きょうのことわざ** — 日付で決まる1件をタイトルに表示。タップでずかんのそのページへ
- **記録を保存** — 正答率・最高連続正解・おぼえた数（正解したことがあり、にがてに入っていない数）を localStorage に保存

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらんでタップ（「きょうのことわざ」「あなうめクイズ」「いみクイズ」「にがてだけ」「ずかん」「つかいかた」） |
| クイズ | ↑↓で4択をえらんでタップ。いちばん下の「← もどる」でメニュー（クイズにもどる／やめてタイトルへ） |
| 解説 | タップで「▶ つぎへ」、↑↓←→で「← もどる」に切り替え |
| 結果 | ↑↓でえらんでタップ（「もう一度」「にがてだけ」「ずかん」「タイトルへ」） |
| ずかん | ←→でめくる、↑↓で行（あ・か・さ…）をとぶ、タップでメニュー（「← ずかんにもどる」「きょうのことわざへ」「にがてだけ ON/OFF」「タイトルへ」） |
| つかいかた | タップで「← タイトルにもどる」 |
| PC確認用 | Escape でひとつ前の画面へ、クリックでも選択可（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?demo=1` を付けると**録画用**のデモモードになります（出題順を固定し、1問目・2問目の正解位置を固定。記録は保存しません）。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%81%93%E3%81%A8%E3%82%8F%E3%81%96&appUrl=https%3A%2F%2Fglass-kotowaza.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスことわざ`、URL `https://glass-kotowaza.vercel.app` を入力。
